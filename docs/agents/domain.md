# Domain Docs

Before exploring or naming domain concepts, read the root [`CONTEXT.md`](../../CONTEXT.md) and every [ADR](../adr/) relevant to the task.

Use the glossary's defined terms in issue titles, proposals, hypotheses, and tests. Avoid synonyms that `CONTEXT.md` explicitly rejects. If a proposed change conflicts with an accepted ADR, name that conflict instead of silently overriding the decision.
