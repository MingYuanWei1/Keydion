# Internationalization

Keydion supports English (`en`) and Simplified Chinese (`zh`). Wrap user-facing runtime text with Flask-Babel `_()` and use `_l()` for module-level lazy values. Ask output follows the UI locale; generated abstracts and keywords follow the selected Paper language; EE/IA metadata transcription preserves the document language verbatim.

After adding or changing a `_()` or `_l()` source string, run:

```bash
python3 tools/extract_translations.py
python3 tools/update_translations.py
python3 tools/compile_translations.py
```

Fill new or fuzzy `msgstr` entries before considering the change complete. If only `msgstr` values changed, run only `compile_translations.py`. Restart or reload the app after compilation because Flask-Babel caches the compiled catalogs.
