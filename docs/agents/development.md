# Development

## Dependencies

Install the locked Python dependencies:

```bash
python3 -m pip install --require-hashes -r requirements.lock
```

`requirements.lock` is generated by pip-tools; edit `requirements.txt`, then follow [Updating Python dependencies](../../README.md#updating-python-dependencies) instead of editing the lockfile directly.

## Run locally

Run Flask on the host against an already bootstrapped, current database:

```bash
PAPERQUERY_ALLOW_DEV_SECRET=1 PAPERQUERY_COOKIE_SECURE=0 \
python3 -m flask --app wsgi run --debug --port 4000
```

`create_app()` rejects an empty or default secret unless `PAPERQUERY_ALLOW_DEV_SECRET=1`; `PAPERQUERY_COOKIE_SECURE=0` is required for a plain-HTTP development session. See [Operations](operations.md) for database bootstrap and schema rules.

## Environment

Use `.env.example` as the variable reference. `config.py` loads `.env.prod` when it exists and otherwise loads `.env`, so `.env.prod` wins when both are present.

## Development container

`docker-compose.yml` is machine-local and gitignored. Inspect its `x-keydion-volumes` list before relying on container behavior, and rebuild after changing a source file that is not mounted:

```bash
docker compose up -d --build
```

Tests are not included in the image; run them on the host. If a tool replaces a single-file bind mount and the container still serves the old inode, restart the affected container.
