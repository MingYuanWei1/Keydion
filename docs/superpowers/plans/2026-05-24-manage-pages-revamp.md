## Background context for the implementer

You're working in `Keydion`, a single-file Flask app (`app.py` is ~5,500 lines, all routes/models/helpers in one module). Read `CLAUDE.md` at the repo root before starting — it documents conventions you'll need.

Specifically:
- **DB session pattern:** `with db_session() as db: ...` then `db.query(Model)...` then `db.commit()` inside the block. NOT `db.session.query(...)` — there is no Flask-SQLAlchemy.
- **Auth:** `user = require_login(level=N)` returns the user dict or `None`. Level 2 = editor (Contributor), level 3 = admin (Curator). Return JSON 401 on failure for JSON endpoints (don't redirect from a JSON endpoint).
- **i18n:** All user-visible strings wrapped in `_("...")` (or `_l("...")` for lazy). After editing `.po` files, run `python tools/compile_translations.py` to produce `.mo` files.
- **Tests:** Contract tests under `tests/`. Most use `ast` to parse `app.py` and substring-match the source, OR read templates as strings and substring-match. Two integration-style tests (`test_dashboard_url_nesting_contract.py`) use `app.test_client()` with `sqlite:///:memory:`. We will use the latter style for the new endpoints because they have real logic worth exercising.
- **No CSRF:** The existing JSON POST endpoints (e.g. `news_categories_add` at app.py:2408) accept POSTs without CSRF tokens. Match this convention — do NOT add CSRF tokens on the new endpoints.

The handoff package lives at `handoff/` in the repo root. After implementation, you may leave `handoff/` in place; it is reference material.

### Known issues in the handoff templates that this plan fixes

1. **`news_manage.html` line 437** uses `parseInt(c.value, 10)` to collect selected article IDs. But `NewsArticleModel.id` is a 12-char hex string (e.g. `"a1b2c3d4e5f6"`, generated by `uuid4().hex[:12]` at app.py:2265). `parseInt("a1b2c3d4e5f6", 10)` returns `NaN`. Fix: change to just `c.value`.
2. **`news_manage.html` line 443** uses a fragile conditional `{{ url_for('news_bulk_action') if 'news_bulk_action' in (config.get('ROUTES') or []) else '#' }}` for the fetch URL. Fix: hoist a clean `var BULK_URL = "{{ url_for('news_bulk_action') }}";` to the top of the script and use `BULK_URL` in the fetch.
3. **`guide_manage.html` lines 275–276** ship with `var REORDER_URL = null;` and `var TOGGLE_URL_TEMPLATE = null;`. We will replace those with real `url_for(...)` values.

    @app.route("/dashboard/news/bulk_action", methods=["POST"], endpoint="news_bulk_action")
    def news_bulk_action():
        user = require_login(level=2)
        if not user:
            return jsonify(error="Unauthorized"), 401
        data = request.get_json(silent=True) or {}
        ids = [str(x) for x in (data.get("ids") or [])]
        op = data.get("op")
        if op not in {"publish", "unpublish", "delete"}:
            return jsonify(error="bad op"), 400
        affected = 0
        with db_session() as db:
            rows = db.query(NewsArticleModel).filter(NewsArticleModel.id.in_(ids)).all()
            for r in rows:
                if op == "publish":
                    r.status = "published"
                    if not r.published_at:
                        r.published_at = datetime.utcnow().isoformat()
                elif op == "unpublish":
                    r.status = "pending"
                elif op == "delete":
                    db.delete(r)
                affected += 1
            db.commit()
        return jsonify(ok=True, affected=affected)

```

Notes on this code:
- `ids` are coerced to `str` because `NewsArticleModel.id` is `Unicode(255)`.
- Publishing a never-published article stamps `published_at`, matching app.py:4291 behavior.
- `op="unpublish"` maps to `status="pending"` — the app uses `pending` for drafts, not `"draft"`.

    @app.route("/dashboard/admin/guides/reorder", methods=["POST"], endpoint="admin_guides_reorder")
    def admin_guides_reorder():
        user = require_login(level=3)
        if not user:
            return jsonify(error="Unauthorized"), 401
        data = request.get_json(silent=True) or {}
        items = data.get("items") or []
        with db_session() as db:
            for it in items:
                try:
                    gid = int(it.get("id"))
                except (TypeError, ValueError):
                    continue
                g = db.query(GuideModel).filter_by(id=gid).first()
                if not g:
                    continue
                try:
                    g.sort_order = int(it.get("sort_order"))
                except (TypeError, ValueError):
                    pass
                if "category" in it:
                    g.category = (it.get("category") or "").strip()
                g.updated_at = datetime.utcnow().isoformat()
            db.commit()
        return jsonify(ok=True)

    @app.route("/dashboard/admin/guides/<int:guide_id>/toggle", methods=["POST"], endpoint="admin_guide_toggle_published")
    def admin_guide_toggle_published(guide_id: int):
        user = require_login(level=3)
        if not user:
            return jsonify(error="Unauthorized"), 401
        data = request.get_json(silent=True) or {}
        with db_session() as db:
            g = db.query(GuideModel).filter_by(id=guide_id).first()
            if not g:
                return jsonify(error="not found"), 404
            if "published" in data:
                g.published = bool(data["published"])
            else:
                g.published = not bool(g.published)
            g.updated_at = datetime.utcnow().isoformat()
            new_state = bool(g.published)
            db.commit()
        return jsonify(ok=True, published=new_state)

```
