# 双语文档

[English](README.md) | 中文

本规范定义了跨语言管理与翻译技术文档的通用标准，以英文与简体中文作为参照语言对。它确立配对约定、结构同步、术语规则与质量校验。

- [translation-rules.md](translation-rules.md) 定义核心翻译与行文规则。
- [terminology.md](terminology.md) 是技术术语真源。
- [style-samples.md](style-samples.md) 提供常见技术文体的参照语体对。
- [translation-prompt.md](translation-prompt.md) 提供标准化的 LLM（大语言模型）翻译流水线提示词。

## 配对约定

- **两种语言同权。** 一篇文档可以先用任一语言撰写和评审，另一侧由它翻译而来。两个文件谁也不高于谁；约束它们的是二者必须传达相同的技术内容、语气与意图。
- **同目录文件配对。** 在基于文件的文档仓库中，每份本地化文件与其源文件互为同目录兄弟文件（例如 `foo.md` 与 `foo.zh.md`），或遵循显式的语言目录映射。同目录配对避免翻译沦为相互脱节的孤岛。
- **语言切换行。** 每份本地化文档在 H1 主标题后立即提供清晰的双向切换行：
  - 英文源：`English | [中文](foo.zh.md)`
  - 中文对侧：`[English](foo.md) | 中文`
- **结构与对侧一一对应。** 文档的结构骨架与对侧一一对应：标题深度与层级、列表类型、列表项数量、表格行列数、逐字节一致的围栏代码块、链接目标都必须对齐。完整保持规则见 [translation-rules.md](translation-rules.md)。

## 自动化校验

1. **配对完整性：** 范围内的每篇文档都有所有目标语言的对应文件。
2. **结构一致性：** 标题层级、列表项数量、表格行列数、围栏代码块的数量与种类在两侧保持一致。
3. **代码块完整性：** 围栏代码块与机器可读标识符在译文两侧逐字节一致。
4. **链接可解析：** 所有内部链接与相对链接在两种语言版本中都指向有效目标，没有死链。
5. **同步跟踪：** 修改一侧而未更新对侧、也未更新同步元数据时，触发警告或校验失败。
